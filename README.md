# Environnement de développement

## Prérequis

- **JDK** : Java 21 (compatible OpenJDK)
- **Build Tool** : Maven 3.9+
- **Serveur** : Tomcat 10 (intégré via Spring Boot)
- **Base de données** : MySQL 8.0+
